### 🚨 SIRENS — Multi-Agent Urban Crisis Response System

<table border="0" width="92%">
<tr>
<td valign="top" width="68%">

> *Detect → Classify → Plan → Execute → Verify → Evaluate — a fully autonomous emergency-response loop.*

A five-agent system built for Pakistani metropolitan cities: a Classifier agent normalizes and scores incoming signals (weather, news, citizen reports), a Planner generates prioritized response plans, an Executor acts through Genkit tools, a Verification agent uses citizen voting as a human-in-the-loop safeguard against false positives, and an Evaluator measures whether the response actually worked. Real-time maps, push alerts, and full agent-trace transparency for authorities.

### 🔁 Magitly — Self-Healing CI/CD Pipeline

<table border="0" width="92%">
<tr>
<td valign="top" width="68%">

> *A codebase that fixes itself before a human ever sees the failure.*

A LangGraph-based multi-agent pipeline where a **Planner** agent evaluates incoming code changes before **Reviewer**, **Refactor**, and **Testing** agents detect, fix, and validate issues — autonomously. A pre-LLM secret-scanning gate stops exposed credentials from ever reaching the model, and a bounded 3-attempt retry-and-repair loop escalates unresolved issues instead of silently committing an unvalidated fix. Integrated with GitHub via MCP, with event-triggered workflows that watch repository activity and kick off the right agent pipeline automatically.
